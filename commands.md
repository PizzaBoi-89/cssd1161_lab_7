## 1. git clone: copies a repository of your Git.
## 2. git pull: fetches and merges updates.
## 3. git remote add origin <URL>: remotely connects using the URL to your Github.
## 4. git checkout: creates an isolated branch to work on your code without impacting your acual branch you're working on.
## 5. git push -u origin main -: Pushes local commits remotely to Github.
## 6. git init: turns a local repository into a new Git repository
## 7. git add: stages all modified and new files at once
